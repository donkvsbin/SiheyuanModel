                    四合院虚拟现实游
              Siheyuan Virtual Reality Tour
═══════════════════════════════════════════════════════════════

【项目简介】
基于 Three.js + Rapier3D 构建的四合院虚拟游览系统，
融合传统文化体验与现代 Web 技术，支持第一人称漫游、
任务系统、AI 对话、拍照收集等互动功能。


【系统要求】
─────────────────────────────────────────────────────────────
操作系统：Windows 10/11、macOS、Linux
运行环境：Node.js 20+（LTS 长期支持版）
浏览器：Chrome、Edge、Firefox（推荐 Chrome）

Node.js 下载地址：https://nodejs.org


【运行方式】
─────────────────────────────────────────────────────────────
方式一：本地运行（推荐）

  1. 解压文件，进入 dist 文件夹
  2. 在文件夹地址栏输入 cmd，按回车打开终端
  3. 输入命令：npx serve
  4. 浏览器访问：http://localhost:3000

方式二：在线体验

  直接访问：https://mellomade.online


【操作指南】
─────────────────────────────────────────────────────────────
移动控制：
  W/A/S/D     - 前后左右移动
  鼠标        - 转动视角
  空格        - 跳跃（地面）/ 上升（飞行模式）
  Shift       - 加速奔跑（地面）/ 下降（飞行模式）
  V           - 切换飞行模式

功能按键：
  F           - 与物体交互 / 继续对话
  ESC         - 打开/关闭设置面板
  K           - 打开/关闭任务面板
  L           - 打开/关闭四合院图鉴
  P           - 拍照（保存精彩瞬间）
  O           - 打开照片画廊
  H           - 打开 AI 小助手

界面说明：
  左上角      - 小地图（实时显示位置和朝向）
  右上角      - XYZ 坐标和 FPS 显示
  右下角      - 键位提示（K/L/O/P/H）


【项目结构】
─────────────────────────────────────────────────────────────
dist/           - 构建好的前端文件（可直接运行）
src/            - Vue 3 源代码
  components/   -  Vue 组件（场景、UI、小游戏）
  game/         - 游戏系统（任务、对话、收集）
  utils/        - 工具类（后期处理、国际化）
public/         - 静态资源（模型、图片、音乐）


【技术栈】
─────────────────────────────────────────────────────────────
前端：Vue 3 + Vite + Three.js + Rapier3D
后端：Spring Boot（AI 对话接口）
部署：Nginx + 云服务器


【注意事项】
─────────────────────────────────────────────────────────────
1. 首次加载需要下载 3D 模型资源，请耐心等待
2. 建议使用独立显卡以获得流畅体验
3. AI 助手功能需要联网访问后端服务
4. 拍照功能生成的图片保存在浏览器本地存储中
